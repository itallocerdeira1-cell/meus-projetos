# Regras do projeto

1. Em interfaces, a direção visual vem da design-taste-frontend; a ui-ux-pro-max serve só para estrutura, usabilidade e acessibilidade, nunca para escolher estilo.

2. Antes de começar qualquer projeto novo ou funcionalidade nova, use a skill grilling para me entrevistar até o plano estar fechado, mesmo que eu não peça. Pule essa etapa em correções pequenas (erro de digitação, ajuste de cor, um bug pontual) ou quando eu escrever 'sem perguntas'.

3. Figuras científicas (gráficos, mapas, curvas, forest plots, para artigo, resumo, pôster ou slide) seguem a skill figuras-cientificas deste repositório, que substitui a graficos-em-r. Python é o padrão; R só quando eu pedir.
